# PDF to JPEG Converter

A simple, easy-to-use web-based PDF to JPEG converter. Upload a PDF file and convert all pages to JPEG images.

## How to Use
Visit the converter at: [https://htmlfan123.github.io/PDF-to-JPEG/](https://htmlfan123.github.io/PDF-to-JPEG/)

## Technology

- Uses [PDF.js](https://mozilla.github.io/pdf.js/) library for PDF rendering
