# PDF to JPEG Converter

A simple, easy-to-use web-based PDF to JPEG converter. Upload a PDF file and convert all pages to individual JPEG images instantly in your browser.

## Features

- **Drag & Drop Support** - Simply drag your PDF file onto the page or click to browse
- **Batch Conversion** - Automatically converts all pages in your PDF
- **Download Images** - Download each page as a JPEG file individually
- **Client-Side Processing** - All conversion happens in your browser—your files stay private
- **No Installation Required** - Works directly in your web browser

## How to Use

1. Visit the converter at: [https://htmlfan123.github.io/PDF-to-JPEG/](https://htmlfan123.github.io/PDF-to-JPEG/)
2. Upload a PDF file by:
   - Clicking the "Choose a PDF file" button, or
   - Dragging and dropping a PDF onto the drop zone
3. Wait for the conversion to complete
4. Download each page as a JPEG image

## Technology

- Built with vanilla JavaScript and HTML5
- Uses [PDF.js](https://mozilla.github.io/pdf.js/) library for PDF rendering
- No backend server required—everything runs in your browser
